# 🚀 Quick Start - Course System API Tests

## One-Line Execution

### Windows PowerShell (Recommended)
```powershell
cd src\tests\scripts; .\run-course-system-tests.ps1 -InstallNewman -Verbose
```

### Windows Batch
```cmd
cd src\tests\scripts && run-course-system-tests.bat --install-newman --verbose
```

### Linux/Mac
```bash
cd src/tests/scripts && ./run-course-system-tests.sh --install-newman --verbose
```
